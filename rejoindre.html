Nous rejoindre

Votre commune envisage de reprendre MAT ? Présentez-vous : nous pourrons vous orienter, et les communes qui ont déjà fait le chemin pourront vous proposer leur aide.

Remplir le formulaire de demande

Le formulaire est sur GitHub et demande un compte gratuit. Comment créer un compte GitHub

Ce que le formulaire vous demande

  • le nom de votre commune, sa population et son département ;
  • les compétences disponibles : élu, secrétaire de mairie, agent, habitant bénévole… ou personne pour l’instant ;
  • votre prestataire informatique, si vous en avez un ;
  • votre besoin, en quelques phrases.

Comptez cinq minutes.

Ce qui se passe ensuite

  1. Votre demande apparaît sur GitHub, visible par tous.
  2. Une commune ambassadrice ou l’équipe de Mézières-lez-Cléry vous répond sous votre demande. GitHub vous prévient par courriel.
  3. Selon votre situation, on vous oriente vers le guide pas à pas, l’entraide ou le prochain webinaire.

Votre demande sera publique

N’y indiquez ni numéro de téléphone, ni adresse personnelle, ni clé ou mot de passe. C’est ce qui permet aux autres communes de la lire, et à une commune voisine de vous proposer son aide.
