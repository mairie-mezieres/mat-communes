L’entraide entre communes

Une question posée en public aide toutes les communes : celle qui la pose, et toutes celles qui se la poseront demain. Les communes qui ont déjà fait le chemin y répondent.

Ouvrir l’espace d’entraide Je n’ai pas de compte GitHub

Pour lire les échanges, aucun compte n’est nécessaire. Pour écrire, il faut un compte GitHub gratuit : le mode d’emploi est plus bas sur cette page.

Trois règles avant d’écrire

  1. Tout est public. N’écrivez ni numéro de téléphone, ni adresse personnelle, ni nom d’habitant.
  2. Jamais de clé ni de mot de passe, même en partie, même dans une capture d’écran. Pour parler d’une clé, donnez son nom (par exemple UPSTASH_REDIS_REST_TOKEN), jamais sa valeur.
  3. Cherchez avant de demander : dans les questions fréquentes et dans l’espace d’entraide. Votre question y a peut-être déjà sa réponse.

Si une clé a été publiée par erreur, régénérez-la tout de suite depuis le service qui l’a donnée : la supprimer du message ne suffit pas.

Créer un compte GitHub pour écrire, en trois écrans

GitHub est le site qui héberge MAT et cet espace d’entraide. Le compte est gratuit. Les écrans sont en anglais : voici quoi y chercher.

  1. Écran 1 sur 3

    S’inscrire

    Ouvrez github.com/signup. Saisissez l’adresse électronique de la mairie (Email), un mot de passe (Password) et un nom (Username), par exemple mairie-saint-exemple. Cliquez sur Continue. GitHub peut vous demander de résoudre un petit jeu, pour vérifier que vous n’êtes pas un robot.

  2. Écran 2 sur 3

    Confirmer l’adresse

    GitHub envoie un code par courriel. Recopiez-le dans la case prévue. Si rien n’arrive, regardez dans le dossier des indésirables.

  3. Écran 3 sur 3

    Écrire votre message

    Revenez sur l’espace d’entraide, choisissez un des cinq espaces, puis cliquez sur le bouton vert New discussion (« nouvelle discussion »). Donnez un titre clair, écrivez, puis cliquez sur Start discussion.

Vous recevrez un courriel de GitHub à chaque réponse.
